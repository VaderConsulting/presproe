 DESCRIPTION:
------------------------------------------------------------------------------
 ResourcePro looks on your system for any "hidden" resources in program files
 and automatically extrats them to a folder.


 REQUIRES:
------------------------------------------------------------------------------
 * Visual Basic 5 oder higher
